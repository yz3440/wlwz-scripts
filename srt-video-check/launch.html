SRT Video Check Tool

This tool helps you check and edit SRT subtitle files against video files. Due to browser security restrictions, local video files must be accessed through a web server.

Important: Before using this tool, you need to set up a local server to serve the files correctly.

Option 1: Python Simple Server

If you have Python installed, open a terminal/command prompt and run: 

cd /path/to/wlwz-scripts
python -m http.server

Then click the button below:

Open with Python Server (Port 8000)

Option 2: Node.js http-server

If you have Node.js installed, you can use http-server:

npm install -g http-server
cd /path/to/wlwz-scripts
http-server

Then click the button below:

Open with http-server (Port 8080)

Option 3: Direct File Access (May Not Work)

Some browsers may allow direct file access, but this is not recommended and may not work correctly:

Try Direct Access (Not Recommended)

For more information and troubleshooting, please refer to the README file.
